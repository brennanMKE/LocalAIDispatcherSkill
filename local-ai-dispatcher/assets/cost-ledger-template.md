# Cost ledger

Measured token counts from this project's dispatcher subagents, captured as they
were reported.

**Why this file exists.** These figures are reported **once**, in a completion
notification, and exist nowhere else — not in git, not in a log, not in any API.
When a session ends they are gone. Anything not written down here at the moment it
was measured is unrecoverable.

**Rate:** {model} — ${IN}/MTok input, ${OUT}/MTok output. The subagent figure is
**combined**, with no input/output split, so cost is computed at an assumed
**85% input / 15% output** = **${COMBINED}/MTok**. State the assumption inline
wherever a figure derived from it appears — a number whose derivation is invisible
is indistinguishable from an invented one.

**Local implementation is $0.00** at any volume and is not listed here.

## What this total does and does not cover

**Covers:** every dispatcher subagent spawned — the review and verification layer
around delegated rounds.

**Does not cover:** main-loop authoring and review (issue writing, diff review, doc
work, merges). The harness reports no per-turn usage and there is no `count_tokens`
call available from inside a session. **That spend is real and is larger than the
figure above** — it is simply not measurable here. Track closing the gap as its own
issue rather than guessing.

## Recording rule

**Write a measurement down in the same turn it is reported.** A number held only in
conversation context is already lost. The same applies to wall times, round counts,
and any number the harness surfaces once.

## Local token volume

Tracked separately, regenerated by `./scripts/tally-local-tokens.sh --markdown`.
It comes from OpenCode's SQLite database, which is the only durable record — the
dispatch logs carry no token counts and the model server exposes no historical usage
endpoint. This file covers the hosted side, which is the number that is not zero.
